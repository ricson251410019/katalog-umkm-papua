### Deskripsi Proyek
Website katalog yang memperkenalkan contoh produk kerajinan,
kuliner, dan minuman yang terinspirasi dari Papua.

### Teknologi yang Digunakan
1. HTML5 untuk struktur halaman website.
2. CSS3 untuk warna, tipografi, jarak, dan tata letak.
3. Flexbox untuk menyusun navigasi dan bagian hero.
4. CSS Grid untuk menyusun kartu produk.
5. Media query untuk menyesuaikan tampilan dengan ukuran layar.

### Struktur File
- index.html: struktur dan konten website.
- style.css: desain dan tata letak responsif.
- README.md: dokumentasi proyek.
- screenshots/: bukti pengujian ukuran layar.

### Pengujian Responsif
- Mobile: 375 x 667 px.
- Tablet: 768 x 1024 px.
- Desktop: 1366 x 768 px.

Screenshot dimasukkan setelah setiap ukuran layar benar-benar diuji.

### Cara Menjalankan
Buka website melalui browser atau tautan GitHub Pages
yang tersedia pada repositori.

### Catatan
Nama produk dan harga yang ditampilkan merupakan contoh
untuk kebutuhan pembelajaran, bukan penawaran dari penjual tertentu.
