## Deskripsi
Website katalog sederhana untuk memperkenalkan contoh produk
kerajinan, kuliner, dan minuman yang terinspirasi dari Papua.

## Teknologi
- HTML5: struktur dan isi halaman.
- CSS3: warna, tipografi, jarak, dan desain.
- Flexbox: navigasi dan susunan bagian hero.
- CSS Grid: tata letak kartu produk.
- Media query: menyesuaikan tampilan berdasarkan lebar layar.

## Cara Menjalankan
1. Buka index.html melalui browser atau GitHub Pages.
2. Pilih menu Beranda, Produk, atau Tentang.
3. Periksa susunan katalog pada ukuran layar berbeda.
